# La Riuà — concepto web no oficial

Independent restaurant design demo; not commissioned or endorsed by La Riuà.

Static HTML/CSS/JavaScript, ready for GitHub Pages. Open index.html or serve the folder with a local web server. No build or dependencies.

Features: responsive navigation, category filters, accessible image lightbox, FAQ, reduced-motion support, working official booking/contact links, and content available without JavaScript.

Edit dishes and prices in index.html (menu.json is a reference export). Photos are remote Unsplash inspiration images supplied in the original design, not actual restaurant photos. Replace with approved client photography for commercial use.

Public sources checked 2026-10-04: https://www.lariua.com/carta and https://www.lariua.com/reservas. This is a selection, not the full restaurant menu. Confirm prices and allergens directly.

Publish: GitHub Settings → Pages → Deploy from a branch → main / root.
